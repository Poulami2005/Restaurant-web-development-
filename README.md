# 🍛🍕 Bengal & Basil

Bengal & Basil is a responsive restaurant website built using HTML, CSS, and JavaScript. The website showcases a fusion of Indian and Italian cuisines with an elegant user interface and seamless navigation.

## ✨ Features

- Responsive design for desktop and mobile devices
- Indian Delights menu section
- Italian Classics menu section
- Customer reviews section
- Upcoming events showcase
- Table reservation form
- Modern card-based food menu layout
- Smooth scrolling navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
